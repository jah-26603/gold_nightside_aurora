Development is still required for full dataset production from the GOLD mission. The main things that need to be addressed before publication:

1) Apply the method to channel A and channel B respectively from the GOLD instrument.
2) Figure out how to handle limb segmentation during the local summer. Local summer limb pixels are currently being predicted as aurora with the current model.
3) A science investigation. This method takes a lot of inspiration from the dayside paper, so a new spin will have to be applied with the new dataset.
